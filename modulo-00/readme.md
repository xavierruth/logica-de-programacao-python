# 🛠️ Módulo 00: Configuração e Ambiente de Desenvolvimento

Antes de começar a programar em Python, precisamos preparar o nosso ambiente de trabalho.

---

## 📥 Ferramentas Utilizadas
* **VS Code:** IDE recomendada para execução dos códigos localmente.
* **Google Colab:** Alternativa online baseada em navegadores.

#### IDEs online que podem ser usadas para práticar: 

- Online Python 
- Replit 
- myCompiler

---

## ⚙️ Passo a Passo de Instalação

### 1. Instalando o Python
Abra a **Microsoft Store** do seu computador e busque por:

* Python 

Em seguida, escolha a versão mais recente _(no meu caso foi a versão Python 3.14)_ e instale em seu computador. 

### 2. Verificando o Python
Abra a barra de busca do seu computador e pesquise por **Prompt de Comando (CMD)** e clique. Quando o **CMD** abrir, digite: 
```bash
python --version 
``` 

### 3. Instalando o VS Code 
Abra a **Microsoft Store** do seu computador e busque por: 

* VS Code ou Visual Studio Code 

Em seguida, instale em seu computador. 

### 4. Extensões no VS Code 
Abra o VS Code e instale as seguintes extensões: 

- Python
- Jupyter 
- Portuguese (Brazil) Language Pack for Visual Studio Code

### 5. Abrindo o Jupyter Notebook 
No VS Code, utilize as teclas: 
``` bash
CTRL + SHIFT + P 
```
Digite **Jupyter** e selecione a opção:
``` bash
Create: Novo Jupyter Notebook
```
