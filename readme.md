## 🛠️ 1. Preparando o Ambiente de Desenvolvimento

Antes de programar, verifique se as ferramentas estão instaladas no seu computador:

### Ferramentas Recomendadas
* **VS Code** (com as extensões `Python` e `Jupyter` instaladas)
* **Google Colab** (alternativa online para rodar os cadernos Jupyter diretamente no navegador)

### Verificando a Instalação do Python
Abra o **Prompt de Comando (CMD)** ou Terminal e digite:
```bash
python --version
```
